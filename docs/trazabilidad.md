# Trazabilidad

Formato obligatorio para citas (Restricción 2 — trazabilidad completa). Toda
afirmación debe poder remontarse a:

- **documento** (título e identificador, p.ej. PD-01, Reglamento UE 2015/703,
  Regulamento 826-2023, prescriptions GRDF)
- **país / jurisdicción** (ES · PT · FR · UE)
- **versión** del documento (redacción vigente / fecha)
- **artículo / tabla / anexo / párrafo**
- **página**
- **fragmento extraído** (texto literal de respaldo)
- **identificador de chunk** (para preguntas vía RAG)
- **URL oficial** de la fuente
- **fecha de ingestión**

Toda respuesta debe ser reconstruible por un auditor a partir de estos metadatos.
